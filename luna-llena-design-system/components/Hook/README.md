Hook / headline — Bricolage Grotesque ExtraBold, tight tracking, premium. The brand always highlights the keyword in orange.

```jsx
<Hook highlight="no">Los 8 lugares que no podés saltearte</Hook>
```

Pass `highlight` with the keyword (first match goes orange). For historia, set `size="var(--h-idea-size)"`. Keep hooks short and punchy — one idea.

**Alineación** — `align="left" | "center"`. Si no la pasás, hereda `--text-align` (left por
defecto del sistema). La alineación se decide por estilo, no por componente.
