The visite.ar wordmark with its orange `.ar` — use in the top bar of any template.

```jsx
<LogoMark variant="white" size={28} />
<LogoMark variant="dark" showHandle />
```

Variants: `white` (default, for dark/photo backgrounds) and `dark` (for light backgrounds; its `.ar` uses `--primary-on-light`). Set `showHandle` to render `@visite.ar` on the right, spanning the container width — handy for headers.
