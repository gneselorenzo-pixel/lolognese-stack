Kicker / label — SemiBold uppercase, open tracking, orange. Sits above a hook or titular.

```jsx
<Kicker>Argentina sin errores</Kicker>
```

Always uppercase and orange by default — this is the brand's label voice. Use `--h-kicker-size` (28px) for historia.

**Alineación** — `align="left" | "center"`. Si no la pasás, hereda `--text-align` (left por
defecto del sistema). La alineación se decide por estilo, no por componente.
