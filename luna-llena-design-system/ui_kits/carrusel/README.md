# Carrusel — 1080×1350

The flagship Instagram format. A deslizable set of slides:
1. **HookSlide** — photo + overlay + ExtraBold hook (keyword in orange) + "Deslizá" chip.
2. **ListSlide** — solid dark, big ghost number, titular + bajada per point.
3. **CTASlide** — blanco, "comentá KEYWORD" ManyChat call-to-action.

`index.html` renders an interactive, scaled preview (arrow keys / on-screen nav).
Slides live in `CarruselSlides.jsx` and compose the DS components from
`window.VisiteArPeru`.

Safe padding: 80px. Logo top-left, index top-right. Signature bar on every text block.
