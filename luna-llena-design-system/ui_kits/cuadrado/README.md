# Cuadrado — 1080×1080

Single-post square format.
- **SquareDato** — a dato / cita on solid dark, hook with orange keyword + optional bajada.
- **SquareFoto** — full-bleed photo + overlay with a short hook.

`index.html` is an interactive scaled preview; variants live in `CuadradoSlides.jsx`.
Logo top-left (with handle on dato posts), signature bar on the text block.
