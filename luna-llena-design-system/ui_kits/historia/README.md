# Historia — 1080×1920

Vertical story format. **One idea per slide, lots of air, casual.** Not mini-editorials.
- **HistoriaFoto** — full-bleed photo + overlay, idea anchored above the bottom safe area.
- **HistoriaTexto** — solid dark, single big idea centered, optional short bajada.
- **HistoriaCTA** — "deslizá para arriba" / comentá prompt.

Respects Instagram safe areas (top 230px for the progress bar/header, bottom 320px for the
reply UI). `index.html` is an interactive scaled preview; slides in `HistoriaSlides.jsx`.
